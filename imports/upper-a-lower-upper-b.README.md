# Import your rotating split

Use **Settings → Merge selected data → Choose merge backup**, select `upper-a-lower-upper-b.forge.json`, select the program under Programs, review the automatically linked exercises, then confirm the merge. The file contains one program, three workouts and 19 exercise definitions. It contains no workout history, measurements or food logs.

Use selective merge to add this program to your current data. **Do not use Replace my data** for this file: that action replaces the whole document, including your existing history.

Rotation: **Upper A → Lower → Upper B → rest → repeat**. Rest is a day off, not an empty workout.

- Cable crunch: original rest range is 60–90 seconds; the single-value rest timer is set to 90 seconds.
- Split squat or step-up: choose either movement; targets are per leg.
- Dead bug: targets are per side; log 0 kg external weight.
- Side plank: **2 × 20–40 seconds per side**, 60 seconds rest. Forge has no timed-hold field. Its name and notes retain the time target. The numeric repetition target is a **1 completed hold on both sides** placeholder per set. Use a separate timer and log 1 rep / 0 kg after each pair of holds; do not interpret it as a one-second target.
- Exercise definitions have dedicated IDs so they do not overwrite your existing exercise mappings. Muscle-contribution weights are editable estimates.
