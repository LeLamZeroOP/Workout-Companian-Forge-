## Notable decisions and additional source evidence

- The neutral-grip lat pulldown stays with Physique Development because its [creator description](https://www.youtube.com/watch?v=KgZqDuNx7rI) provides useful chapters: active ROM 0:23, grip 1:15, setup 2:08, technique 2:50 and mistakes 3:15. The existing 4:55 episode is already a useful full tutorial.
- The chest-supported dumbbell row stays with That Fit Friend. The [creator video](https://www.youtube.com/watch?v=TXjeZsqCVsg) chapters technique at 0:00, benefits 2:19 and tips 3:31; the [creator article](https://thatfitfriend.com/chest-supported-dumbbell-row-guide/) independently documents bench setup and elbow path.
- The overhead cable extension stays with Geoffrey Verity Schofield. The [creator description](https://www.youtube.com/watch?v=dVtMz69MOb0) explicitly identifies form, programming and common mistakes in the 6:41 episode.
- For chin-ups, Scott Herman's [creator article](https://muscularstrength.com/article/Four-Dumbest-Chin-Up-Mistakes-Sabotaging-Back-Growth) corroborates that the selected episode addresses the actual chin-up plus beginner progression, rather than substituting an overhand pull-up.
- For straight-arm pulldowns, the selected [Colossus creator description](https://www.youtube.com/watch?v=vJwAbr_pVVM) lists pelvic-position correction, excessive elbow bend, and proper-form instruction. John Meadows' [exercise index alternative](https://www.youtube.com/watch?v=_ZsprFzatDo) is a credible exact movement but only 2:49; the chosen 4:24 episode better meets the requested instruction depth.
- For preacher curls, the [publisher article](https://www.menshealth.com/fitness/a42473298/preacher-curl-machine/) supports the exact machine setup, while the [YouTube description](https://www.youtube.com/watch?v=R-8Sa0_qiws) identifies coached machine instruction by Ebenezer Samuel, C.S.C.S. Selected over the 2:01 [Atlasthetics tutorial](https://www.youtube.com/watch?v=VUxZuml-jNE) and RP's 16-second exercise index.
- For cable curls, the [publisher's cable-curl section](https://www.menshealth.com/fitness/a20694771/hammer-curl/) identifies the same episode and a 6:16 runtime. It demonstrates a single-handle variation, so the JSON carries an attachment note. The prior [Fit Father tutorial](https://www.youtube.com/watch?v=NFzTWp2qpiE) is exact but only 1:59; retain it as an alternative if a bilateral bar-only demonstration is required. The [PD facing-in alternative](https://www.youtube.com/watch?v=5z4y7QRTx1w) is only 1:22. Scott Herman's [barbell-versus-cable comparison](https://www.youtube.com/watch?v=mYf7QhCRYFw) is longer but primarily comparative, so I did not choose it merely to reach a runtime threshold.
- For machine rows, the [RP creator chapters](https://www.youtube.com/watch?v=6eBwGki2JuU) explicitly delimit machine row at 9:37 and the next exercise at 13:00. JSON starts at 577 seconds. This gives the exact exercise 3:23 of focused coverage. The prior PureGym machine tutorial is only about a minute; several search results claiming form tutorials were 30–65 seconds. If a standalone is mandatory, [Men's Health's Hammer Strength row article](https://www.menshealth.com/fitness/a42588105/hammer-strength-row/) is a promising creator-source lead but its YouTube ID was not verified during this review.
- For Smith JM presses, [Alex Leonidas' creator description](https://www.youtube.com/watch?v=RO5KcSbYXho) explicitly labels Smith-machine technique at 0:44 and switches to SSB at 6:15. JSON starts at 44 seconds and identifies the segment boundary. This is preferable to the existing 30-second PD demonstration and the 2:41 [Atlasthetics exact tutorial](https://www.youtube.com/watch?v=6oaUT4GYHkw), while matching the actual equipment. The latter is an exact shorter fallback if the parent finds a playback issue.
