## Tracking conventions

Muscle contribution values are editable training-volume estimates: 1 for a selected direct target and 0.5 for a selected indirect contributor. They are not physiological measurements. The restricted 13-muscle model cannot represent forearms or brachialis. Reverse barbell curls therefore have no tracked direct target and receive only 0.5 biceps credit; hammer and Zottman variants disclose the omitted muscles in setup notes. Traps and rhomboids map to upperBack. Core and hinge stabilizers do not automatically receive set credit.

For assisted pull-ups/chin-ups and band-assisted pull-ups, record 0 kg external load and assistance details in notes. More assistance means less demand and must not be interpreted as more external performance. Ordinary bodyweight entries log 0 kg unweighted and added external load when weighted. Variable band tension is documented by band and setup, with 0 kg avoiding a fabricated fixed free-weight equivalent. Machine plate and stack entries need a consistent load convention and machine identity in notes. Dumbbell entries explicitly state the per-dumbbell convention.

## Exercise definition review

Rows receive lats/upperBack direct credit when both shoulder extension and scapular retraction are deliberately loaded. The wide-grip seated row emphasizes upperBack and rearDelts directly, with lats/biceps indirect. Vertical pulls have lats direct and biceps/upperBack indirect. Shrugs have upperBack direct. Dumbbell pullovers have chest/lats direct; machine pullovers use lats direct and chest indirect. Curls have biceps direct except the reverse curl's forearm-dominant tracking limitation described above. No invented regional biceps categories or untracked muscles were added.
