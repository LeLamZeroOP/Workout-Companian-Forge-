# Built-in training library

57 common exercises are available to new and existing users. Saved definitions take precedence over built-ins. Saving a program atomically includes missing built-in exercises that it references, in both local and cloud mutation paths. Workout history is preserved.

Four Forge templates offer 3-, 4-, 5- and 6-day schedules. These are original exercise selections and prescriptions inspired by public split structures, not copies of paid programs or official endorsements. The 6-day PPL schedule repeats three workouts twice each week. Imported programs, workouts and template exercises receive fresh IDs. Attribution and schedule remain in program notes and exports.

Public sources consulted 27 September 2026:
- [Jeff Nippard: The Smartest Push Pull Legs Routine](https://www.youtube.com/watch?v=qVek72z3F1U)
- [Jeremy Ethier: The BEST Workout Split to Build Muscle](https://builtwithscience.com/fitness-tips/best-workout-split-2025/)
- [Renaissance Periodization: Training Frequency](https://rpstrength.com/blogs/articles/many-days-train-per-week)

Effective-set muscle contributions are editable tracking estimates, not measured physiological coefficients. Bodyweight exercise notes use added external weight (0 kg for unweighted sets). Timed exercises are excluded because the logger tracks repetitions.


## Muscle-set summaries in the local continuation

The local continuation adds per-muscle sets by explicit repeat cycle, direct/indirect explanations, optional user targets, and a current-plan versus completed view. Seven-day averages require explicit schedules; the PPL preview counts each workout twice. Legacy definitions without reviewed roles show unknown direct counts. The two-split comparison remains to be implemented. See [the plan](superpowers/plans/2026-09-27-split-muscle-volume.md). This work is not yet published; current prescriptions and source attribution remain unchanged.


The local exercise expansion adds Upper chest / Mid chest emphasis details beneath Chest, 12 chest variants and five supporting movements. Parent totals and historical mappings remain intact. The food catalog expansion was canceled and is not part of this work.
